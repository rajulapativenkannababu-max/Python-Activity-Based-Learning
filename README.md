This repository contains the Python Activity-Based Learning assignment. Ten case studies
were selected from the case study list and each one is solved with the ten deliverables
that were asked for: problem statement, objectives, assumptions, algorithm, flowchart,
pseudocode, Python source code, test cases, output screenshot and conclusion.

All the programs use only the topics covered in the syllabus — variables, data types,
operators, conditional statements, loops, strings, pattern generation, lists, nested lists,
tuples, tuple operations and unpacking. No dictionaries, sets, `try/except`, `lambda` or
modules are used anywhere.

## Folder Structure

Every case study folder contains:

```
01-examination-result-grace-marks/
    README.md               - the ten deliverables of that case study
    solution.py             - the Python program
    test_cases.py           - the test cases, checks the output automatically
    flowchart.png           - flowchart of the program
    output.txt              - the output of the program
    output_screenshot.png   - screenshot of the output
    demo_input.txt          - the input values (only for menu-driven programs)
```

## How to Run

Go into any case study folder and run the program:

```bash
cd 01-examination-result-grace-marks
python solution.py
```

The test cases can be checked with:

```bash
python test_cases.py
```

For the programs that ask for input, the values that were typed are listed in
`demo_input.txt`, and the same values were used to produce `output.txt`.
